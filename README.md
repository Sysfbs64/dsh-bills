# dsh-bills

DSH (DeepSeek Harness) Web GUI 的模型用量账单插件：按会话聚合模型调用的 token
用量，按 DeepSeek 官方峰谷价目表（人民币）逐次计价，增量同步 + 磁盘缓存常驻，
账单以**会话标签页**形式整页阅览。

## 功能特性

- **会话标签页阅览**：会话头部新增「账单」按钮（会话标签栏也常驻「账单」标签），
  点击后账单在会话主区域整页展开，不再挤在设置面板的小窗口里。
- **时间窗口**：统计卡片、按天分模型柱状图、Token 热力图、按会话明细表统一支持
  `7 天 / 14 天 / 30 天 / 自定义`（自定义起止日期）窗口，默认近 7 天。
- **按会话明细**：明细表紧随热力图展示；每行含窗口内费用与峰/谷拆分，展开可查看
  该会话在窗口内的逐日花费明细。
- **计价规则**：DeepSeek 官方人民币价目表，峰谷定价于 2026-08-17（北京时间）生效；
  高峰 = 北京 09-12、14-18 点，空闲 = 高峰一半；**自 2026-08-23（北京时间）起
  周末（周六、周日）全天为低谷价**（生效前的调用保持旧规则，不追溯）。
  其余模型按官方美元价 × 6.79 折算（2026-08 央行中间价）。
- **增量同步**：启动基线 + 会话事件实时增量 + 60 秒轮询水位线；非 live 历史会话
  永不重读；缓存版本升级时自动全量重算。

## 安装
需要确保pnpm可用。
```
dsh plugin --profile web add github:Sysfbs64/dsh-bills
```

## 数据与缓存

- 数据来源：会话日志中 `assistant/message` 事件的 token 用量（输入 / 输出 /
  缓存读 / 缓存写 / 推理），按调用时间逐次计价。
- 磁盘缓存：工作区 `.bills-cache.json`（v4）。含按会话按日折叠与按日分模型聚合，
  时间窗口统计直接由此派生；由宿主 `/api/dsh-bills/summary`、`/api/dsh-bills/charts`
  路由提供，浏览器半部同源 fetch 读取。
- 缓存版本升级（数据结构变更）会忽略旧缓存并触发一次全量基线重算。

## 免责声明

费用为估算值（元 / 百万 tokens）：计费输入 = 输入（缓存未命中）+ 缓存写，缓存读按
命中价单列。仅供参考，非实际账单；如有出入以 DeepSeek 官方账单为准。
