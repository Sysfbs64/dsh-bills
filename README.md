# dsh-bills

DSH Web GUI 模型用量账单插件：按会话聚合模型调用 token 用量，按 DeepSeek 官方
峰谷价目表（人民币）逐次计价，增量同步 + 磁盘缓存常驻，账单以**会话标签页**
形式整页阅览。

## 功能

- **会话标签页阅览**：在会话头部点击「账单」按钮（或直接点击会话标签栏的
  「账单」标签），账单页在会话主区域整页展开，不再挤在设置面板里。
- **时间窗口**：统计卡片、按天分模型柱状图、Token 热力图、按会话明细表统一
  支持 `7 天` / `14 天` / `30 天` / `自定义`（起止日期）窗口，默认近 7 天；
  明细表紧随热力图展示，展开会话可查看窗口内逐日花费。
- **计价规则**：DeepSeek 官方峰谷价（高峰 = 北京 09-12、14-18 点，空闲 = 高峰
  一半；**自 2026-08-23（北京时间）起周末全天为低谷价**，生效前调用按旧规则
  计价）；其余模型按官方美元价 × 6.79 折算（2026-08 央行中间价）。
- **增量同步**：启动基线 + 会话事件实时增量 + 60 秒轮询水位线；非 live 历史
  会话不重读；缓存版本升级时自动全量重算。

## 安装

```sh
dsh plugin add link:~/code/dsh-bills
```

重启 `dsh web` 后，任意会话头部出现「账单」按钮。

## 结构

```text
lib/index.js    宿主半部：事件折叠、计价、增量同步、/api/dsh-bills/* 路由、磁盘缓存
lib/client.js   浏览器半部：账单标签页视图（时间窗口 / 图表 / 明细表 / 悬浮层）
cordis.patch.yml   bundle 补丁：向 web profile 注册插件行
```

## 数据与缓存

- 数据来源：会话日志中 `assistant/message` 事件的 token 用量，按调用时间逐次计价。
- 磁盘缓存：工作区 `.bills-cache.json`（v4）；含按会话按日折叠与按日分模型
  聚合，供时间窗口统计。
- 费用为估算值（元 / 百万 tokens），仅供参考，非实际账单。

## 开发

```sh
node --check lib/index.js lib/client.js   # 语法检查
```

宿主折叠 / 序列化 / 计价逻辑可用假会话事件驱动整条链路做端到端验证。
